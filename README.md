# AutoCutAI

긴 영상 촬영본을 넣으면, AI가 재미없는 부분은 잘라내고 필요한 부분만
남겨서 "편집안"을 만들어주는 프로그램입니다.

직접 영상을 편집하려면 촬영본을 처음부터 끝까지 다 보면서 어디를 자를지
정해야 합니다. AutoCutAI는 이 작업을 AI에게 맡기고, 사람은 결과물을
DaVinci Resolve에서 확인하고 다듬을 수 있도록 만들어졌습니다.

코딩을 전혀 몰라도 따라 할 수 있도록 설치와 사용 방법을 설명합니다.
프로젝트 구조나 코드 내부가 궁금한 개발자분은 `DEVELOPMENT.md`를
참고하세요.

## 이런 분들에게 유용합니다

-   유튜브/브이로그 촬영본이 너무 길어서 편집이 막막한 분
-   게임 방송 다시보기에서 하이라이트만 뽑고 싶은 분
-   예능/토크 콘텐츠를 여러 대 카메라로 찍고, 편집 순서 정리부터 막막한
    분
-   다큐멘터리·인터뷰 촬영본을 시간순으로 정리하는 것부터 손이 많이 가는
    분

## 주요 기능

### 영상 하나를 넣고 자동으로 편집안 만들기

영상의 지루한 구간, 침묵, NG 등을 AI가 분석하고 살릴 부분을 판단해 편집
계획을 만듭니다.

결과에는 어떤 구간을 남길지, 잘라낼지, 빠르게 재생할지 등의 정보가
포함됩니다.

### 폴더째로 여러 영상 분석하기

영상 파일이 여러 개 들어 있는 폴더를 한 번에 지정할 수 있습니다.

파일 하나에서 오류가 발생하더라도 가능한 경우 나머지 영상의 분석을 계속
진행하도록 구성되어 있습니다.

### 다큐멘터리 영상 자동 정렬

촬영 순서가 뒤죽박죽인 경우에도 영상의 내용을 분석해 다큐멘터리 형식에
적합하다고 판단되면 시간 흐름에 맞게 정렬할 수 있습니다.

### 예능/버라이어티 스타일 편집 지원

리액션, 티키타카, 재미있는 순간 등은 살리고 어색한 침묵이나 같은 설명의
반복 등은 줄이는 방식으로 편집안을 만들 수 있습니다.

### 멀티캠 자동 인식 및 앵글 전환

파일 이름에 촬영 시각과 카메라 이름을 일정한 규칙으로 넣어두면 같은
순간에 촬영된 여러 카메라 영상을 자동으로 묶을 수 있습니다.

예를 들어 다음과 같은 파일 이름을 사용할 수 있습니다.

``` text
20260914_153000_거치1cam.mp4
20260914_153002_pov1cam.mp4
```

카메라를 정확히 같은 프레임에 맞춰 동시에 시작할 필요는 없습니다. 몇 초
정도의 시작 시간 차이는 같은 촬영분으로 묶을 수 있도록 처리됩니다.

멀티캠 촬영분이 감지되면 리액션이나 중요한 순간 등에 맞춰 어느 카메라를
사용할지 결정한 편집안을 만들 수 있습니다.

### 영상 분위기 및 배경음악 스타일 추천

편집안을 만들 때 영상의 분위기와 어울리는 배경음악 스타일도 함께 제안할
수 있습니다.

### DaVinci Resolve로 내보내기

편집 계획을 XML 파일로 내보내면 DaVinci Resolve에서 타임라인으로 가져와
이어서 작업할 수 있습니다.

배속이 적용된 구간도 XML에 반영되어 Resolve에서 실제 재생 속도에 맞게
가져올 수 있습니다.

### 모바일 연동 API

vNext에서는 Android와 같은 모바일 클라이언트에서 영상을 업로드하고
서버에서 분석 및 편집안을 생성할 수 있는 API 서버를 제공합니다.

진행 상태와 결과를 JSON/XML 형태로 받을 수 있습니다.

## 중요한 점

AutoCutAI가 만드는 것은 "완성된 영상"이 아니라 "이렇게 잘라서 편집하면
어떨까?"라는 편집 초안입니다.

AI가 만든 결과를 그대로 사용할 수도 있지만, 최종 편집은 DaVinci Resolve
등의 편집 프로그램에서 사람이 확인하고 수정하는 것을 전제로 합니다.

# 시작하기 전에 준비할 것

## 1. Python

Python 3.11 이상이 필요합니다.

### Windows

[Python 공식 사이트](https://www.python.org/downloads/)에서 Python 3.11
이상을 설치하세요.

Windows에서 설치할 때 설치 화면 아래쪽의 다음 항목을 반드시 체크하는
것을 권장합니다.

``` text
Add Python to PATH
```

설치가 끝나면 명령 프롬프트 또는 PowerShell을 열고 다음 명령어를
입력합니다.

``` bat
python --version
```

다음과 같이 나오면 정상입니다.

``` text
Python 3.11.x
```

또는 그 이상의 버전이 표시되면 됩니다.

### macOS

macOS에서는 `python` 대신 `python3` 명령을 사용하는 것이 일반적입니다.

터미널을 열고 다음 명령어를 입력하세요.

``` bash
python3 --version
```

다음과 같이 나오면 정상입니다.

``` text
Python 3.11.x
```

또는 그 이상의 버전이 표시되면 됩니다.

Mac에서 `python --version`을 입력했는데 명령을 찾을 수 없다고 나오는
경우에도 `python3`가 정상적으로 설치되어 있다면 문제가 아닙니다.

이 문서에서 macOS 명령어는 `python3` 기준으로 설명합니다.

### Ubuntu/Linux

터미널에서 다음 명령어로 확인합니다.

``` bash
python3 --version
```

Python 3.11 이상이 필요합니다.

## 2. FFmpeg

FFmpeg는 영상에서 소리를 추출하거나 영상 정보를 처리하는 데 사용됩니다.

AI가 영상 속 대사를 분석하려면 영상의 오디오를 처리해야 하므로 FFmpeg가
필요합니다.

### Windows

[FFmpeg 공식 사이트](https://ffmpeg.org/download.html)에서 Windows용
FFmpeg를 내려받아 설치합니다.

FFmpeg의 `bin` 폴더가 PATH에 등록되어 있어야 합니다.

설치 후 명령 프롬프트에서 다음 명령어로 확인할 수 있습니다.

``` bat
ffmpeg -version
```

버전 정보가 표시되면 정상입니다.

### macOS

Homebrew가 설치되어 있다면 터미널에서 다음 명령어를 입력합니다.

``` bash
brew install ffmpeg
```

설치 후 다음 명령어로 확인합니다.

``` bash
ffmpeg -version
```

Homebrew가 설치되어 있지 않다면 [Homebrew 공식
사이트](https://brew.sh/)의 설치 방법을 참고하세요.

### Ubuntu/Linux

``` bash
sudo apt-get update
sudo apt-get install ffmpeg
```

설치 후:

``` bash
ffmpeg -version
```

으로 정상 설치 여부를 확인합니다.

------------------------------------------------------------------------

## 3. 그래픽카드(GPU)

GPU가 없어도 프로그램은 사용할 수 있습니다.

GPU가 있으면 Whisper 음성 인식 등의 작업을 더 빠르게 처리할 수 있습니다.

NVIDIA GPU와 CUDA 환경이 제대로 구성되어 있는 경우 faster-whisper가
GPU를 사용할 수 있습니다.

GPU를 사용할 수 없는 환경에서는 CPU로 처리할 수 있지만 영상 길이와
컴퓨터 성능에 따라 분석 시간이 상당히 길어질 수 있습니다.

------------------------------------------------------------------------

## 4. AI API 키

AutoCutAI 프로그램 자체는 무료로 사용할 수 있지만, 실제로 영상 내용을
분석하고 편집 판단을 내리는 AI 기능은 외부 AI 서비스의 API를 사용합니다.

지원되는 서비스와 모델은 프로젝트 버전에 따라 달라질 수 있습니다.

예:

-   Google Gemini
-   OpenAI
-   Anthropic Claude
-   OpenRouter

각 서비스의 API 키와 요금 정책은 해당 서비스에서 직접 확인해야 합니다.

Google Gemini는 계정과 API 사용 조건에 따라 무료 사용량이 제공될 수
있지만, 무료 사용 가능 여부와 한도는 변경될 수 있습니다.

API 키는 프로그램을 실행한 뒤 `Settings` 메뉴에서 입력할 수 있습니다.

### API 키 보안 주의

Settings에서 입력한 API 키는 `config/config.json`에 저장됩니다.
API 키는 다른 사람에게 공유하지 마세요.

# 설치하고 실행하기

프로젝트에는 설치와 실행을 자동으로 처리하는 실행 파일이 포함되어
있습니다.

## Windows

Python 설치 후 `run.bat`을 더블클릭합니다.

처음 실행하면 필요한 Python 패키지를 설치하므로 시간이 걸릴 수 있습니다.

검은색 명령 프롬프트 창에 설치 로그가 표시되는 것은 정상입니다.

설치가 끝나면 프로그램 창이 실행됩니다.

두 번째 실행부터는 이미 설치된 환경을 사용하므로 첫 실행보다 빠르게
시작됩니다.

## macOS

Python 설치 후 `run.command`를 실행합니다.

### `run.command`를 처음 실행할 때

macOS의 보안 기능 때문에 다음과 비슷한 경고가 나타날 수 있습니다.

-   확인되지 않은 개발자
-   개발자를 확인할 수 없음
-   Apple에서 악성 소프트웨어가 있는지 확인할 수 없음

신뢰할 수 있는 AutoCutAI 파일을 받은 경우 다음 순서로 실행을 허용할 수
있습니다.

1.  Finder에서 `run.command`를 한 번 실행합니다.
2.  경고가 나타나면 닫습니다.
3.  `시스템 설정`을 엽니다.
4.  `개인정보 보호 및 보안`으로 이동합니다.
5.  아래쪽으로 스크롤합니다.
6.  방금 실행한 앱 또는 파일에 대한 실행 허용 항목이 나타나는지
    확인합니다.
7.  `그래도 열기`를 선택합니다.
8.  다시 확인 창이 나타나면 `열기`를 선택합니다.

macOS 버전에 따라 표시되는 문구와 위치가 조금 다를 수 있습니다.

보안 경고가 나타났다고 해서 무조건 보안 설정을 해제할 필요는 없습니다.
출처를 신뢰할 수 있는 파일인지 먼저 확인하세요.

### `run.command`를 더블클릭해도 실행되지 않는 경우

터미널을 열고 AutoCutAI 폴더로 이동합니다.

예를 들어:

``` bash
cd ~/Downloads/AutoCutAI
```

실제 폴더 위치에 맞게 경로를 변경하세요.

그다음 실행 권한을 추가합니다.

``` bash
chmod +x run.command
```

이후 다음 명령어로 실행합니다.

``` bash
./run.command
```

Python 관련 오류가 나타난다면 다음 명령어로 Python 설치 상태를
확인하세요.

``` bash
python3 --version
```

FFmpeg도 다음 명령어로 확인할 수 있습니다.

``` bash
ffmpeg -version
```

## Ubuntu/Linux

터미널에서 AutoCutAI 폴더로 이동한 뒤:

``` bash
./run.sh
```

을 실행합니다.

실행 권한 오류가 발생하면:

``` bash
chmod +x run.sh
./run.sh
```

를 사용합니다.

# 직접 설치하고 실행하기

원클릭 실행 파일을 사용하지 않고 직접 설치할 수도 있습니다.

먼저 GitHub 저장소에서 프로젝트를 다운로드합니다.

GitHub 페이지에서:

``` text
Code → Download ZIP
```

을 선택하고 압축을 원하는 위치에 풉니다.

그다음 터미널 또는 명령 프롬프트를 열고 AutoCutAI 폴더로 이동합니다.

## Windows

``` bat
cd AutoCutAI
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

## macOS / Linux

``` bash
cd AutoCutAI
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 app.py
```

### 다음에 다시 실행할 때

가상환경을 사용하는 경우 먼저 가상환경을 활성화한 뒤 프로그램을
실행합니다.

Windows:

``` bat
.venv\Scripts\activate
python app.py
```

macOS/Linux:

``` bash
source .venv/bin/activate
python3 app.py
```

`pip install -r requirements.txt`는 필요한 패키지가 이미 설치되어 있다면
매번 실행할 필요가 없습니다.

# macOS에서 수동 설치할 때 주의할 점

macOS에서 다음과 같이 입력하는 대신:

``` bash
python -m venv .venv
```

다음처럼 입력하는 것을 권장합니다.

``` bash
python3 -m venv .venv
```

가상환경을 활성화한 뒤에는:

``` bash
source .venv/bin/activate
```

를 사용합니다.

활성화되면 터미널 앞부분에 다음과 비슷하게 표시될 수 있습니다.

``` text
(.venv)
```

설치 명령어는 다음처럼 실행합니다.

``` bash
python3 -m pip install -r requirements.txt
```

프로그램 실행:

``` bash
python3 app.py
```

만약 가상환경이 활성화된 상태라면 다음처럼 `python`으로 실행해도
가상환경의 Python을 사용할 수 있지만, 초보자는 이 문서의 `python3`
명령어를 그대로 사용하는 것을 권장합니다.

# 처음 실행했을 때 할 일

프로그램을 처음 실행하면 왼쪽에 다음과 같은 메뉴가 표시됩니다.

-   Home
-   AI Chat
-   AI Editor
-   Settings
-   Diagnostics

버전에 따라 메뉴 이름이나 구성이 조금 다를 수 있습니다.

## 1. Settings

`Settings` 메뉴로 들어갑니다.

## 2. AI 서비스 설정

사용하려는 AI 서비스의 API 키를 입력합니다.

예를 들어 Gemini를 사용하는 경우:

-   API Key
-   사용할 Model
-   Active 상태

등을 설정하고 저장합니다.

사용 가능한 모델 이름은 사용하는 API 서비스와 프로젝트 버전에 따라
달라질 수 있으므로, README에 특정 모델 이름을 고정해서 입력하기보다는
해당 서비스에서 현재 사용할 수 있는 모델을 확인하세요.

## 3. Diagnostics

`Diagnostics` 메뉴에서는 프로그램 실행에 필요한 환경을 확인할 수
있습니다.

가능한 경우 다음과 같은 정보를 확인합니다.

-   GPU 사용 가능 여부
-   CPU/GPU 실행 모드
-   FFmpeg 인식 여부
-   Python 환경
-   Whisper 관련 환경

프로그램이 실행되지 않거나 분석 단계에서 오류가 발생한다면 Diagnostics를
먼저 확인하는 것을 권장합니다.

# 실제 사용 방법

## 영상 한 편 분석하기

1.  `AI Editor` 메뉴를 엽니다.
2.  `Select Video...`를 누릅니다.
3.  분석할 영상을 선택합니다.
4.  필요하다면 `편집 지침`에 원하는 스타일을 입력합니다.
5.  `Generate Edit Plan`을 누릅니다.
6.  AI 분석이 끝날 때까지 기다립니다.
7.  결과 화면에서 편집 계획을 확인합니다.
8.  결과가 괜찮으면 `Export XML`을 눌러 XML 파일을 저장합니다.

편집 지침 예시:

``` text
웃긴 부분 위주로 남기고 3분 이내로 줄여줘.
```

또는:

``` text
게임에서 중요한 장면과 재미있는 반응만 남겨줘.
```

또는:

``` text
불필요한 침묵과 반복되는 설명은 최대한 제거해줘.
```

영상의 내용과 원하는 결과를 구체적으로 적을수록 AI가 편집 방향을
판단하는 데 도움이 될 수 있습니다.

# DaVinci Resolve로 가져오기

AutoCutAI에서 `Export XML`을 사용해 XML 파일을 저장합니다.

DaVinci Resolve에서:

``` text
File → Import → Timeline...
```

을 선택한 다음 AutoCutAI가 만든 XML 파일을 선택합니다.

그러면 편집 계획에 따라 타임라인이 생성됩니다.

이후에는 DaVinci Resolve에서:

-   컷 수정
-   자막 추가
-   음악 추가
-   색보정
-   효과 추가
-   오디오 조정
-   최종 렌더링

등의 작업을 진행하면 됩니다.

AutoCutAI는 Resolve에서 최종 편집을 하기 위한 초안을 만드는 도구라고
생각하면 됩니다.

# 멀티캠 촬영 파일 이름 규칙

여러 대의 카메라로 같은 장면을 촬영했다면 파일 이름에 날짜, 시간, 카메라
이름을 넣는 것을 권장합니다.

형식:

``` text
날짜_시간_카메라이름.확장자
```

예:

``` text
20260914_153000_거치1cam.mp4
20260914_153002_pov1cam.mp4
20260914_153001_거치2cam.mp4
```

시간은 촬영 시작 시각을 기준으로 합니다.

카메라들을 정확히 같은 순간에 시작하지 않아도 됩니다. 몇 초 정도의
차이가 있는 경우 같은 촬영분으로 묶을 수 있도록 처리됩니다.

다만 파일 이름의 시간 정보가 실제 촬영 시간과 크게 다르거나 규칙이 서로
다르면 멀티캠 인식 결과가 달라질 수 있습니다.

# 문제 해결

## 프로그램 창이 실행되지 않습니다

먼저 Python이 정상적으로 설치되어 있는지 확인합니다.

Windows:

``` bat
python --version
```

macOS/Linux:

``` bash
python3 --version
```

그다음 FFmpeg를 확인합니다.

``` bash
ffmpeg -version
```

Windows에서는 명령 프롬프트, macOS/Linux에서는 터미널에서 실행합니다.

원클릭 실행 파일을 사용했다면 검은색 터미널 창에 표시된 오류 메시지를
확인하세요.

------------------------------------------------------------------------

## macOS에서 `run.command`가 실행되지 않습니다

다음 순서로 확인합니다.

1.  `run.command`를 한 번 실행합니다.
2.  `시스템 설정 → 개인정보 보호 및 보안`으로 이동합니다.
3.  아래쪽에 실행을 허용하는 항목이 나타나는지 확인합니다.
4.  `그래도 열기`를 선택합니다.

그래도 실행되지 않으면 터미널에서 AutoCutAI 폴더로 이동한 뒤:

``` bash
chmod +x run.command
./run.command
```

을 실행합니다.

터미널에 표시되는 오류 메시지를 확인하면 원인을 찾는 데 도움이 됩니다.

------------------------------------------------------------------------

## `python` 명령을 찾을 수 없습니다

Windows에서는 Python 설치 과정에서 `Add Python to PATH`를 체크했는지
확인합니다.

macOS에서는 `python` 대신:

``` bash
python3 --version
```

을 사용하세요.

macOS/Linux의 수동 설치 과정도 다음과 같이 `python3`를 사용합니다.

``` bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 app.py
```

------------------------------------------------------------------------

## `ffmpeg` 명령을 찾을 수 없습니다

FFmpeg가 설치되어 있는지 확인하세요.

``` bash
ffmpeg -version
```

Windows라면 FFmpeg의 `bin` 폴더가 PATH에 등록되어 있는지 확인합니다.

macOS라면 Homebrew를 사용하는 경우:

``` bash
brew install ffmpeg
```

Ubuntu/Linux:

``` bash
sudo apt-get install ffmpeg
```

------------------------------------------------------------------------

## GPU를 사용하지 않습니다

GPU가 있다고 해서 항상 자동으로 GPU를 사용하는 것은 아닙니다.

다음 항목을 확인하세요.

-   NVIDIA 드라이버
-   CUDA 관련 라이브러리
-   faster-whisper / CTranslate2 환경
-   프로그램의 Whisper 설정
-   Diagnostics의 GPU 상태

NVIDIA GPU가 없는 컴퓨터에서는 CPU로 동작할 수 있습니다.

------------------------------------------------------------------------

## Whisper에서 CUDA 또는 DLL 오류가 발생합니다

Windows에서 다음과 같은 오류가 발생할 수 있습니다.

``` text
Library cublas64_12.dll is not found or cannot be loaded
```

이 문제는 Python 코드 하나만의 문제가 아니라 CUDA 관련 라이브러리,
CTranslate2, NVIDIA 드라이버, Python 환경 등의 조합에서 발생할 수
있습니다.

먼저 프로그램의 `Diagnostics` 정보를 확인하세요.

그다음 현재 가상환경이 활성화되어 있는지 확인합니다.

Windows:

``` bat
.venv\Scripts\activate
```

Python과 CTranslate2 버전을 확인합니다.

``` bat
python --version
python -c "import ctranslate2; print(ctranslate2.__version__)"
```

CUDA를 사용할 수 있는지 확인하는 것도 도움이 됩니다.

``` bat
python -c "import ctranslate2; print(ctranslate2.get_supported_compute_types('cuda'))"
```

이 명령어가 정상적으로 결과를 출력한다고 해서 실제 Whisper 음성
디코딩까지 반드시 정상이라는 의미는 아닙니다.

CUDA 관련 DLL 오류가 계속되면 오류 메시지 전체를 확인한 뒤 현재 Python
가상환경과 설치된 NVIDIA 패키지를 함께 점검해야 합니다.

중요한 내용은 최대한 유지하고 침묵만 제거해줘.

``` text
최종 영상이 5분을 넘지 않도록 중요한 부분만 남겨줘.
```

AI가 만든 편집안은 초안이므로 최종 결과는 DaVinci Resolve에서 직접
확인하는 것이 좋습니다.
