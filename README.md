# AutoCutAI

**긴 영상 촬영본을 넣으면, AI가 알아서 재미없는 부분은 잘라내고 필요한 부분만 남겨서
"편집안"을 만들어주는 프로그램입니다.**

직접 영상을 편집하려면 촬영본을 처음부터 끝까지 다 보면서 어디를 자를지 정해야 하죠.
이 작업을 AI에게 맡기고, 사람은 결과물을 DaVinci Resolve(무료 영상 편집 프로그램)로
가져와서 확인하고 다듬기만 하면 되도록 만든 도구입니다.

> 코딩을 전혀 몰라도 따라 할 수 있도록 쓴 설명서입니다. 프로젝트 구조나 코드 내부가
> 궁금한 개발자분은 [DEVELOPMENT.md](DEVELOPMENT.md)를 봐주세요.

---

## 이런 분들에게 유용해요

- 유튜브/브이로그 촬영본이 너무 길어서 편집이 막막한 분
- 게임 방송 다시보기에서 하이라이트만 뽑고 싶은 분
- 예능/토크 콘텐츠를 여러 대 카메라로 찍고, 편집 순서 정리부터 막막한 분
- 다큐멘터리·인터뷰 촬영본을 시간순으로 정리하는 것부터 손이 많이 가는 분

## 뭘 할 수 있나요?

- **영상 하나 넣고 자동 편집안 만들기** — 지루한 구간, 침묵, NG를 AI가 알아서 골라내고
  살릴 부분만 남긴 "편집 계획"을 만들어줍니다.
- **폴더째로 넣어서 한 번에 분석하기** — 영상 파일이 잔뜩 든 폴더를 통째로 지정하면,
  안에 있는 영상을 순서대로 다 분석합니다. 파일 하나가 문제가 있어도 나머지는 멈추지
  않고 계속 진행됩니다.
- **다큐멘터리 영상은 자동으로 순서를 맞춰줌** — 촬영 순서가 뒤죽박죽이어도, 영상
  내용을 보고 다큐멘터리 느낌이면 시간 순서대로 자동 정렬해줍니다.
- **예능/버라이어티 스타일 편집 지원** — 리액션, 티키타카, 재미있는 순간은 살리고
  어색한 침묵이나 같은 설명 반복은 잘라내는 식으로, 예능 편집 감각에 맞춘 판단을
  합니다.
- **여러 대의 카메라(멀티캠) 자동 인식 + 앵글 전환** — 파일 이름에 촬영 시각과
  카메라 이름을 규칙대로 넣어두면(`20260914_153000_거치1cam.mp4`처럼), 같은 순간에
  찍힌 여러 카메라 영상을 자동으로 묶고, 리액션이 터지는 순간에는 알아서 다른
  카메라로 전환하는 편집본까지 만들어줍니다.
- **영상 분위기 + 배경음악 스타일 추천** — 편집안을 만들 때 "이 영상은 이런 분위기고,
  이런 느낌의 배경음악이 어울려요"까지 같이 알려줍니다.
- **DaVinci Resolve로 바로 가져가서 이어 작업** — 결과물을 파일로 내보내면, 무료
  버전의 DaVinci Resolve에서도 "Import" 한 번으로 실제 편집 타임라인을 열 수 있습니다.
  배속(빨리 감기) 처리한 구간도 실제로 빨라진 채로 반영됩니다.
- **vNext 모바일 연동 백엔드(API) 추가** — 안드로이드 같은 모바일 클라이언트가 영상을
  업로드하고, 서버에서 분석/편집안을 만든 뒤 진행 상태·결과(JSON/XML)를 내려받을 수 있는
  API 서버를 함께 제공합니다.

>  이 프로그램이 만드는 것은 "다 완성된 영상"이 아니라 **"이렇게 잘라서 편집하면
> 어때요?"라는 초안(편집 계획)**입니다. 실제로 영상을 최종적으로 다듬고 완성하는
> 것은 DaVinci Resolve 같은 편집 프로그램에서 사람이 확인하며 진행합니다.

## 시작하기 전에 준비할 것

컴퓨터에 아래 두 가지만 설치되어 있으면 됩니다. 하나씩 설명할게요.

### 1) Python (프로그램을 실행하기 위한 기본 프로그램)

- [python.org 다운로드 페이지](https://www.python.org/downloads/)에서 **3.11 버전 이상**을
  받아 설치하세요.
- **Windows에서 설치할 때 꼭 체크할 것**: 설치 화면 맨 아래 **"Add Python to PATH"**
  체크박스를 반드시 켜고 설치를 진행하세요. 안 그러면 나중에 명령어가 실행되지
  않습니다.
- 설치가 잘 됐는지 확인하려면, 터미널(윈도우는 "명령 프롬프트" 또는 "PowerShell",
  맥은 "터미널" 앱)을 열고 아래처럼 입력해보세요:
  ```bash
  python --version
  ```
  `Python 3.11.x` 같은 글자가 나오면 성공입니다.

### 2) ffmpeg (영상에서 소리를 뽑아내는 데 필요한 프로그램)

AI가 영상 속 대사를 알아듣기 위해 소리를 따로 추출하는 데 필요합니다.

- **macOS**: 터미널에 `brew install ffmpeg` 입력 (Homebrew가 없다면 먼저
  [brew.sh](https://brew.sh)에서 설치)
- **Windows**: [ffmpeg.org 다운로드 페이지](https://ffmpeg.org/download.html)에서 받은 뒤,
  압축을 풀고 그 안의 `bin` 폴더 경로를 환경변수 PATH에 추가해야 합니다. (검색창에
  "windows ffmpeg path 설정"으로 검색하면 그림으로 된 설명이 많이 나옵니다.)
- **Ubuntu/Linux**: 터미널에 `sudo apt-get install ffmpeg` 입력

### 3) 그래픽카드(GPU)는 없어도 됩니다

GPU가 있으면 분석 속도가 빨라지지만, **없어도 전혀 문제 없습니다.** 프로그램이 자동으로
CPU 모드로 돌아가서 정상적으로 동작합니다. 속도만 조금 차이 날 뿐이에요.

### 4) AI를 쓰기 위한 API 키

이 프로그램 자체는 무료지만, 실제로 "영상을 분석해서 판단"하는 부분은 AI 회사(Google
Gemini, OpenAI, Anthropic Claude, OpenRouter 등)의 서비스를 빌려 쓰는 방식이라 그
회사의 **API 키**가 하나 필요합니다. Google Gemini는 무료로 써볼 수 있는 한도가 있어서
처음 시작하기엔 편한 선택지입니다. API 키는 각 회사 홈페이지에서 무료로 발급받을 수
있고, 프로그램을 실행한 뒤 화면 안의 **Settings(설정)** 메뉴에 입력하면 됩니다. (자세한
방법은 아래 "처음 실행했을 때 할 일"에서 설명합니다.)

## 설치하고 실행하는 방법 (한 번에)

이 저장소 안에는 클릭 한 번으로 설치와 실행을 다 처리해주는 파일이 들어있습니다.
**Python만 미리 설치되어 있으면**, 아래처럼 하면 됩니다.

- **Windows**: `run.bat` 파일을 더블클릭하세요.
- **macOS**: `run.command` 파일을 더블클릭하세요.
  - 처음 실행할 때 "확인되지 않은 개발자입니다" 같은 경고가 뜰 수 있어요. 그럴 때는
    파일을 마우스 오른쪽 버튼으로 클릭 → **"열기"**를 선택하면 한 번만 더 확인하고
    정상적으로 실행됩니다.
- **Linux**: 터미널에서 이 폴더로 이동한 뒤 `./run.sh` 를 입력하세요.

**처음 실행할 때**는 필요한 부품을 자동으로 설치하느라 몇 분 정도 걸릴 수 있습니다
(까만 창에 설치 로그가 쭉 지나갑니다 — 정상입니다). 설치가 끝나면 바로 프로그램
창이 뜹니다. **두 번째 실행부터는** 설치 과정 없이 바로 실행되어 훨씬 빠릅니다.

> 실행 파일이 안 열리거나 오류가 난다면, 화면에 뜬 안내 문구를 먼저 읽어보세요.
> Python이 설치되어 있지 않다는 안내가 뜨면 아래 "시작하기 전에 준비할 것"부터
> 진행하시면 됩니다.

### 명령어를 직접 입력하고 싶다면 (선택 사항)

위 실행 파일 대신 터미널에 직접 명령어를 입력해서 설치할 수도 있습니다:

1. 이 저장소를 다운로드하세요. GitHub 페이지 오른쪽 위의 초록색 **Code** 버튼 →
   **Download ZIP**을 누르고, 원하는 위치에 압축을 풀어주세요.
2. 터미널을 열고, 압축을 푼 폴더로 이동합니다.
   ```bash
   cd AutoCutAI
   ```
3. 아래 명령어를 한 줄씩 순서대로 입력합니다.
   ```bash
   python -m venv .venv
   ```
   Windows라면:
   ```bash
   .venv\Scripts\activate
   ```
   macOS/Linux라면:
   ```bash
   source .venv/bin/activate
   ```
   그다음 필요한 부품들을 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```
4. 실행은 아래 명령어로 합니다:
   ```bash
   python app.py
   ```

> 다음번에 다시 실행할 때는 3번 단계의 `.venv` 활성화 명령어와 `python app.py`만
> 다시 입력하면 됩니다. `pip install`은 처음 한 번만 하면 됩니다. (위의 원클릭
> 실행 파일을 쓰면 이 과정을 전혀 신경 쓸 필요가 없습니다.)

>  **API 키 관련 주의사항**: Settings에서 입력한 API 키는 `config/config.json`
> 파일에 암호화 없이 그대로 저장됩니다. 이 저장소를 GitHub에 올릴 계획이라면, 이
> 파일이 실수로 함께 올라가지 않도록 `.gitignore`에 이미 등록해뒀습니다 — 직접
> `git add`로 강제로 추가하지만 않으면 안전합니다.

## 처음 실행했을 때 할 일

1. 프로그램을 처음 켜면 왼쪽에 메뉴(홈, AI Chat, AI Editor, Settings 등)가 보입니다.
2. **Settings(설정)** 메뉴로 들어가세요.
3. 원하는 AI 서비스(예: Gemini) 칸에 발급받은 API 키를 붙여넣고, 사용할 모델 이름을
   입력한 뒤 그 서비스를 "Active(활성화)"로 선택하고 저장합니다.
4. 이제 **AI Editor** 메뉴로 들어가면 영상 편집 기능을 쓸 수 있습니다.
5. **Diagnostics(진단)** 메뉴에서는 지금 GPU를 쓰고 있는지 CPU를 쓰고 있는지,
   ffmpeg가 잘 인식됐는지 등을 한눈에 확인할 수 있습니다. 실행이 잘 안 될 때
   가장 먼저 확인해보면 좋은 곳입니다.

## 실제로 사용하는 흐름 (영상 한 편)

1. **AI Editor** 메뉴에서 **"Select Video..."** 버튼을 눌러 편집하고 싶은 영상 파일을
   선택합니다.
2. (선택) 화면에 있는 "편집 지침" 칸에 원하는 스타일을 문장으로 적어도 됩니다.
   예: "웃긴 부분 위주로 남기고 3분 이내로 줄여줘"
3. **"Generate Edit Plan"** 버튼을 누르면 AI가 영상을 분석하고 편집 계획을 만듭니다.
   (영상 길이에 따라 시간이 좀 걸릴 수 있어요.)
4. 결과 화면에서 어떤 구간을 남기고/잘라내고/빠르게 재생할지, 그리고 이 영상에
   어울리는 분위기·배경음악 추천까지 확인할 수 있습니다.
5. 마음에 들면 **"Export XML"**을 눌러 파일로 저장하세요.
6. DaVinci Resolve를 열고 **File → Import → Timeline...**으로 방금 저장한 파일을
   불러오면, 편집이 이미 반영된 타임라인이 그대로 열립니다. 여기서부터는 평소처럼
   Resolve에서 다듬으면 됩니다.

## 폴더째로 여러 영상 한 번에 처리하기

1. **AI Editor**에서 **"Select Folder... (Batch)"** 버튼을 누르고, 영상이 여러 개 든
   폴더를 선택합니다.
2. 폴더 안의 영상을 전부 자동으로 분석합니다. 다 끝나면 각 영상이 다큐멘터리
   느낌인지 예능 느낌인지, 그리고 여러 카메라로 찍힌 같은 장면끼리 묶였는지를
   보여주는 결과 창이 뜹니다.
3. 여러 카메라로 찍은 촬영분(멀티캠)이 감지됐다면, **"자동 편집 생성 (XML)"** 버튼
   하나로 어느 순간에 어느 카메라를 보여줄지까지 AI가 정한 편집본을 바로 만들 수
   있습니다.

### 여러 대 카메라로 찍었다면 — 파일 이름 짓는 규칙

같은 순간을 여러 카메라로 찍었을 때, 파일 이름을 아래 규칙으로 지으면 자동으로 인식됩니다:

```
날짜_시간_카메라이름.확장자

예시)
20260914_153000_거치1cam.mp4
20260914_153002_pov1cam.mp4
```

카메라들을 정확히 같은 프레임에 맞춰 누를 필요는 없어요. 사람이 손으로 카메라 여러
대를 순서대로 켜는 정도의 몇 초 오차는 자동으로 같은 촬영분으로 묶어줍니다.

## 자주 묻는 질문

**이 프로그램 자체는 무료인가요?**
네, 프로그램은 무료입니다. 다만 영상을 "분석"하는 두뇌 역할은 Google/OpenAI/Anthropic
같은 회사의 AI 서비스를 빌려 쓰는 거라, 그 회사의 API 요금 정책을 따르게 됩니다.
Google Gemini는 무료로 써볼 수 있는 한도가 있습니다.

**그래픽카드(GPU)가 없는데 써도 되나요?**
네, 됩니다. 속도만 조금 느릴 뿐 CPU만으로도 정상 작동합니다.

**컴퓨터를 잘 몰라서 걱정돼요.**
"설치하는 방법"에 나온 명령어를 순서대로, 화면에 나온 그대로만 입력하면 됩니다.
막히는 부분이 있으면 오류 메시지를 그대로 복사해서 검색해보시거나, 이 저장소의
Issues 게시판에 남겨주세요.

**영상이 실행 중에 멈춘 것 같아요.**
영상 길이와 컴퓨터 성능에 따라 분석에 몇 분씩 걸릴 수 있습니다. 화면 하단의 진행
상태 표시가 계속 바뀌고 있다면 정상적으로 진행 중인 것입니다. **Diagnostics** 메뉴에서
현재 상태를 확인해보세요.

**만들어진 편집본이 마음에 안 들어요.**
AI가 처음부터 완벽하게 맞출 순 없어서, "편집 지침"에 원하는 방향을 구체적으로
적어서 다시 시도해보시는 걸 추천합니다. 최종적으로는 DaVinci Resolve에서 직접
다듬는 것을 전제로 만들어진 도구입니다.

## vNext: 안드로이드/모바일용 API 서버 실행

현재 앱 본체는 데스크톱(`customtkinter`) 기반이며, 모바일은 **별도 클라이언트 + 서버 API**
구조로 지원합니다.

1. 의존성 설치:
   ```bash
   pip install -r requirements.txt
   ```
2. API 서버 실행:
   ```bash
   python scripts/run_mobile_api.py --host 0.0.0.0 --port 8000
   ```
3. 주요 엔드포인트:
   - `GET /api/vnext/health`
   - `POST /api/vnext/jobs` (영상 업로드 + 작업 생성)
   - `GET /api/vnext/jobs/{job_id}` (진행 상태)
   - `GET /api/vnext/jobs/{job_id}/plan` (EditPlan JSON)
   - `GET /api/vnext/jobs/{job_id}/resolve-xml` (Resolve Import용 XML)
   - `GET /api/vnext/jobs/{job_id}/sync-bundle` (데스크톱/Resolve 이어작업용 번들)
