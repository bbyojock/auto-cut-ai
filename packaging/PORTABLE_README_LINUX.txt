Saeron Portable for Linux 64-bit
=================================

Run ./Saeron to start the application.
Python and the application dependencies are bundled.

FFmpeg is included in the portable folder. Whisper models are downloaded on
first use and require an internet connection.

The Linux host must provide a graphical desktop environment and the system
libraries required by Tk/OpenCV. The archive targets common x86_64 Linux
systems.
