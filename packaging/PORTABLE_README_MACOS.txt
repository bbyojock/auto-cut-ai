Saeron Portable for macOS
=========================

Open Saeron.app to start the application.
Python and the application dependencies are bundled.

FFmpeg is included in the application build. Whisper models are downloaded
on first use and require an internet connection.

If macOS blocks the first launch, right-click Saeron.app, choose Open, and
confirm the dialog. Signed and notarized distribution can be added later.
